## Agent reports are claims. Repository state is evidence.

I build decision-intelligence tools that show their work: what they knew, where
it came from, and why they concluded it. Local-first where it matters, and
explainable by construction rather than by afterthought.

## What I care about

> **Agent reports are claims. Repository state is evidence.**

- **Evidence over assertion.** A result that cannot be traced is not a result.
- **Explainable by construction.** If the reasoning only appears in the write-up, it was never in the system.
- **Local-first where it matters.** Your data has no reason to leave the machine.
- **Calm software.** Tools should reduce the number of things you are holding in your head.
